```

```

```
https://cdn.jsdelivr.net/gh/wlongdan/tvbox@a83d6429629e8f283c67b796aedb68cd8a27130f/tv.json
```

## 里面有什么

- **点播 9 站**：全部是直连采集中转（`type=1`），不用 jar、不用账号，列表与详情秒开，播放地址不带 `auth/token/sign` 签名，搜索可用。
- **直播 51 个频道 / 144 条线路**：央视 19 台（CCTV-1~17、CCTV-5+、CGTN）＋卫视 32 台（含深圳卫视）。每台 2–3 条，卡了直接换线路。
- **高清官方 1 组 / 7 条**：CCTV-13、东方、浙江、湖南、东南、内蒙古、山西，均为官方或省级播控 CDN，实测 1080P/720P、首包 0.15–0.3 s、分片 3.6–8 s。

## 直播线路怎么选

1. 先进「央视卫视·全部线路」，每台有 线路1/线路2/线路3，默认线路1 已是该台最优（有官方源就排官方）。
2. 卡住或转圈 → 长按切到线路2、线路3，不用退出重进。
3. 只想要清晰度 → 切到「央视卫视·高清官方」那组，7 个台都是官方 CDN；这组台数少，是因为公共免费源里能稳定拿到 1080P 的官方通道只有这几个。

已排除的坏源：16×16 假高清（`8.138.7.223`）、4K 但码率撑不住的（`event.pull.hebtv.com`）。

## 自动维护

仓库每天 05:07（北京时间）自检一次，不用你开机、不用打开豆包：

- 9 个点播站逐个请求列表接口；**连续 3 天失败才移出**，且保证不少于 6 个站。被移出的站每天复检，连续 2 天恢复就自动加回。
- 每个频道的前两条直播线路各试一次；只有「线路1 连续 3 天不通、线路2 正常」时才互换顺序，**不删台**。
- 有变化就提交，没有变化也会更新自检记录（`last-check.md`、`state.json`）。

所以你电视上这条地址不用改，失效的源会被自动换掉。
